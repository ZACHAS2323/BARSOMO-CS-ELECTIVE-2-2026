# QuestLog // Retro To-Do List

A retro arcade-style to-do list built for the Prelim Examination.

## Run it

Open `index.html` in a browser. No build step or dependency installation is required.

## Included requirements

- Add tasks through a form without refreshing
- JavaScript validation for empty tasks
- Dynamic task list rendering from one state object
- Mark tasks complete and persist status
- Delete individual tasks
- Delete all tasks after a simulated 2-second asynchronous loading state
- Local Storage persistence
- Active, completed, and all-task filters
