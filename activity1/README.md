# Activity 1 Project

This is a standalone version of the Activity 1 form validation project.

## Files
- `index.html` — welcome page
- `signup.html` — sign up form
- `signin.html` — sign in form
- `welcome.html` — success page
- `style.css` — styling
- `script.js` — form validation logic

## Run it
